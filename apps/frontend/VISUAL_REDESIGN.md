# الواجهة الموحدة — تقرير التنفيذ والتحقق

## النطاق والنتيجة

امتدت الهوية الزرقاء الطبية للصفحات العامة إلى جميع المساحات الموجودة، مع Cairo
وRTL/LTR والمظاهر الثلاثة. استُبدل الهيكل القديم بترويسة واحدة وتنقل بحسب الدور.
لوحة المريض تعرض المخطط بجوار المهام، والقياسات في مساحة فلاتر وسجل، والأدوية
والعادات في مساحة ملخص وتفاصيل، والتقارير في ملخص جانبي ومخططات وقراءات.
الطبيب والإدارة والمساعد والملف الشخصي تبقى واجهات تمهيدية صريحة، لا وظائف مختلقة.

لم تتغير API أو AuthProvider أو عمليات React Query أو الحسابات الصحية أو بيانات
الأسبوع التجريبي. لم تُقرأ ملفات البيئة ولم يُجر اتصال بقاعدة البيانات في هذه الجولة.
لم تضاف اعتماديات، ولم يتغير الفرع main، ولم ينفذ commit أو push.

## الملفات المعدلة في هذه الجولة

- `src/styles/globals.css`: توحيد الرموز والأنماط والمقاسات والحوارات والحالات المرئية.
- `src/app/routes.tsx`: إدخال الهيكل المشترك لمساحات الأدوار مع إبقاء المسارات وحراسها.
- `src/auth/RouteAccess.tsx`: أدوات الجلسة داخل الترويسة؛ تحذير عالمي عند فشل إبطالها على الخادم.
- `src/components/layout/DashboardLayout.tsx`, `Header.tsx`, `Sidebar.tsx`,
  `BottomNav.tsx`, `navigation.ts`: الهيكل والتنقل بحسب الدور والجوال والقائمة الإضافية.
- `src/pages/patient/DashboardPage.tsx`, `MeasurementsPage.tsx`, `MedicationsPage.tsx`,
  `HabitsPage.tsx`, `ReportsPage.tsx`: تركيبات الصفحات الجديدة، دون تغيير عملياتها.
- `src/components/health/HabitCard.tsx`, `MedicationForm.tsx`,
  `MedicationScheduleCard.tsx`, `ReportSummary.tsx`: إصلاح العبارات المركبة والحالات
  الديناميكية التي ظهرت عربية أو ملتصقة بالإنجليزية أثناء المراجعة البصرية.
- `src/components/ui/PlaceholderPage.tsx`: عرض موحد ورابط عودة يناسب الدور.
- `src/i18n/locales/ar.ts`, `en.ts`: ثمانية مفاتيح متطابقة للأدوية والتقارير.
- `scripts/design-browser.mjs` (جديد): صور وقياسات واختبارات تفاعل دون DB.
- `scripts/smoke.tsx`: انحدار الهيكل الموحد والتنقل بحسب الدور.
- `package.json`: أمر `test:design-browser`؛ لا تغيير للاعتماديات.
- `../../README.md` وهذا التقرير: توثيق التحقق وحدوده.

حُفظ عمل Home/Auth والمكونات العامة السابق واستُخدمت أساسًا لهذه الجولة.
تعديلات `.gitignore` و`auth-browser.mjs` السابقة لم تُعد كتابتها لهذه المهمة.

التغطية البصرية الكاملة: الصفحات العامة الثلاث، صفحات المريض السبع، صفحتا الطبيب،
وصفحة الإدارة؛ الإنجليزية/فاتح/1440 والعربية/داكن/390، قبل وبعد.
تغطية إضافية للرئيسية والدخول والتسجيل وصفحات المريض الخمس الأساسية:
العربية/فاتح/320، الإنجليزية/داكن/430، العربية/System/768، الإنجليزية/فاتح/1024.
اختُبر تغيير تفضيل النظام فعليًا إلى الفاتح والداكن داخل المتصفح، وليس اختيار System فقط.

اختبارات التفاعل بالعربية عند 320 وبالإنجليزية عند 1024 تشمل تبديل اللغة ست مرات
مع حفظ المسار والاستعلام وhash، التفضيلات وإعادة التحميل، القوائم والتنبيهات،
مفاتيح المخطط وtooltip، التحقق والحوارات، CRUD القياسات وتزامن Dashboard/Reports،
CRUD العادات والتقدم والأسماء الطويلة ثنائية الاتجاه، CRUD الأدوية وتسجيل/إلغاء الجرعة.
تغطي واجهة الحساب التسجيل والحساب المكرر والبيانات الخاطئة والدخول والخروج والأدوار
ومسح Query cache وعدم حفظ الرمز في localStorage أو sessionStorage.

لم يرصد الفحص النهائي تجاوزًا أفقيًا أو تداخلًا في مجموعات الأدوات المفحوصة أو أخطاء
تشغيل أو تحذيرات متصفح غير متوقعة. لم يُستخدم overflow-x:hidden لإخفاء العيوب.
نجحت عينات التباين المقاسة للنص الأساسي والأزرار عند 4.5:1 أو أكثر؛ ليست شهادة WCAG شاملة.

## الأدلة وإعادة التشغيل

- الصور المرجعية: `artifacts/full-design/before/report.json` (26 لقطة رئيسية).
- الصور والقياسات النهائية: `artifacts/full-design/after/report.json`.
- فشل إبطال الجلسة المقصود والتحذير: `artifacts/full-design/auth-warning/report.json`.
- توجد صور viewport إضافية للجوال بجوار الصور الكاملة، لتفادي التباس موضع الشريط الثابت في الصور الطويلة.

من مجلد frontend، مع توفر Playwright وEdge محليًا:

```powershell
# إذا لم تكن Playwright في مسار اعتماديات Node، حدد مسار تثبيتها المحلي أولًا:
$env:PLAYWRIGHT_MODULE_PATH = 'C:\path\to\node_modules\playwright'
npm.cmd run test:design-browser
npm.cmd run test:design-browser -- --auth-warning
```

السكربت يرفض المنفذ 5178 المشغول، ويشغّل ويوقف عملية Vite الخاصة به فقط.
استجابات `/api/auth/*` fixtures داخل المتصفح؛ لا يتصل بالخادم أو PostgreSQL.
هذه اختبارات واجهة وعقود مصادقة وليست إعادة تحقق من المصادقة الخلفية الحقيقية.

## الحدود المتبقية

- تحذيرا Rollup من تعليقات PURE في Zod موجودان؛ البناء ناجح ولم تُعدّل مكتبة الطرف الثالث.
- فاحص الترجمات يعرض تنبيهات استرشادية للمفاتيح الديناميكية أو المحتمل عدم استخدامها؛ لا يحذفها.
- بقيت طبقة ترجمة DOM للمكونات غير المهاجرة؛ حُميت العبارات الجديدة declarative فقط.
- لم يُجر اعتماد إتاحة شامل بقارئ شاشة أو اختبار جميع حالات تكبير المتصفح.
- واجهة اختيار الوقت/التاريخ الأصلية قد تتبع لغة المتصفح/Windows.
- الاختبار الفعلي تم في Edge عبر Vite؛ بناء الإنتاج تحقق بأمر build، وليس مصفوفة متصفحات إنتاج مستقلة.

توقّف التنفيذ بعد إعادة التصميم للمراجعة؛ لا وظائف Backend جديدة ولا تعديل لبيانات المرضى.
