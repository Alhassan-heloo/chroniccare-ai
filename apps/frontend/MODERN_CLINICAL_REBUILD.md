# Modern Clinical SaaS — إعادة التكوين البصري

تاريخ التنفيذ: 21 أكتوبر 2026. النطاق: التطبيق الفعلي داخل `apps/frontend`، وليس النماذج المستقلة.

## المفهوم والاختلاف البنيوي

الرئيسية القديمة: مقدمة مركزية داكنة وعنوان كبير، ثم نافذة منتج منفصلة، وشبكة bento، ورحلة من ثلاث بطاقات، وقسم مساعد ودعوة ختامية.

الرئيسية الجديدة: مقدمة سريرية فاتحة/داكنة بحسب التفضيل، عنوان غير مركزي وشرح وإجراءات موازية، وسجل تفاعلي للأيام السبعة **داخل المقدمة نفسها**. اختيار اليوم يغيّر قيم الضغط والسكر من أمثلة المشروع الأصلية. الأدوات موضّحة بقائمة تبويبات ولوحة تفاصيل واحدة، ثم مسار متابعة متصل بدل تكرار البطاقات والدعوات. لا توجد صورة حاسوب أو شهادات أو أرقام مستخدمين مخترعة.

اللوحة القديمة: لوحة قياسات داكنة بجانب الرسم، ثم ملخصا الدواء والنشاط، ثم المهام.

اللوحة الجديدة: اليوم والترحيب والإجراء أولًا؛ الروتين الفعلي وخطوته التالية ثم أحدث القراءات في مجموعة مترابطة؛ الاتجاهات والتقرير والمساعد في قسم مراجعة لاحق. الغلاف الجديد يضع الشريط العلوي فوق عرض التطبيق كله، والتنقل الهادئ داخل منطقة العمل، بدل الشريط الجانبي الداكن الممتد بجانب الرأس.

## أساس التصميم

- القيم المطلوبة: `#F6F8FA` و`#EEF3F6`، نص `#1F2A37`، علامة `#3F6E8C`، accent طبي `#5FA7A3`، highlight `#DCEAF2`.
- الداكن: `#17212B`، أسطح `#22303D`، primary `#6D97B2`، accent `#71B7B0`، نص `#EAF0F4`.
- تُستخدم درجة أفتح للنصوص الصغيرة في الداكن لتحقيق التباين؛ اللون الطبي ليس تصنيفًا للحالة الصحية.
- Cairo المحلي وبنية CSS/Tailwind الحالية محفوظان. لا مكتبات أو صور أو خطوط خارجية جديدة.
- قواعد التكوين الجديدة محددة بـ `clinical-*`؛ بقيت محتويات الصفحات الأخرى وبنية CSS في مكانها. تغيّر التوكنز المشتركة لون الهوية، لا منطقها أو تكوين محتواها.
- انتقالات دخول خفيفة وتغذية بصرية للضوابط وتبويبات الأدوات؛ تُحترم إعدادات تقليل الحركة. تُحفظ إعدادات Light/Dark/System من المزود القائم دون مزود جديد.

## الملفات التي عُدلت في هذه المهمة فقط

1. `src/pages/public/HomePage.tsx` — التكوين الجديد، مع استمرار استخدام session/demo والملاحة الحالية.
2. `src/components/public/ClinicalPreview.tsx` — ملف جديد؛ سجل الأيام وتبويبات الأدوات والوصول بلوحة المفاتيح.
3. `src/components/public/PublicLayout.tsx` — علامة نطاق للهوية الجديدة؛ نفس الرأس والتذييل والروابط.
4. `src/pages/patient/DashboardPage.tsx` — إعادة تركيب العرض؛ الاستعلامات والمكونات والإجراءات الأصلية نفسها.
5. `src/components/layout/DashboardLayout.tsx` — إعادة تركيب الغلاف فقط؛ Outlet والأدوار والسياق وحوار القياس محفوظة.
6. `src/styles/globals.css` — توكنز الهوية والقواعد المحددة النطاق والاستجابة والوصول والحركة.
7. `src/i18n/locales/ar.ts` — مفاتيح جديدة ضمن `public.clinical` و`patient.clinical`، دون حذف ترجمات قائمة.
8. `src/i18n/locales/en.ts` — المفاتيح الإنجليزية المطابقة.
9. `scripts/smoke.tsx` — تحديث توقعات البنية البصرية وإضافة تأكيدات التكوين الجديد، مع إبقاء اختبارات الوظائف.
10. `scripts/design-browser.mjs` — وضع `--clinical-design` لصور قبل/بعد والقياسات والتفاعلات.
11. هذا التقرير.

بقية التغييرات الظاهرة في Git كانت موجودة مسبقًا؛ لم تُلغَ أو تُنسب لهذه المهمة. لم تُعدّل أي ملفات backend أو PostgreSQL أو مجلدات `design-prototypes`، ولم تُعدّل محتويات صفحات القياسات والأدوية والعادات والتقارير والطبيب والمشرف. لم تُضف اعتماديات أو تُغيّر المسارات أو أذونات الأدوار.

## سلامة الوظائف والترجمة

- `usePatientDashboard` وReact Query ومخازن API التجريبية وحسابات التقارير والأهداف والجرعات لم تتغير.
- حافظت اللوحة على `MedicationCard` و`HabitCard` و`AlertCard` و`AssistantCard` و`WeeklySummary` و`MeasurementForm`.
- بقيت أمثلة 7 أيام ومؤشراتها، وحالات التحميل والخطأ وإعادة المحاولة والفراغ.
- المعاينة العامة منفصلة عن سجل المريض، وتقرأ `demoWeeklyMeasurements` القائمة؛ لا تستبدل بيانات اللوحة بقيم ثابتة.
- النص الجديد يستخدم المزود والكتالوج والمنسقات المركزية القائمة. حماية `data-i18n="declarative"` بقيت في نطاق النصوص المهاجرة، ولم تُوضع على مجموعة المهام التي قد تحتوي محتوى قديمًا أو مدخلات مستخدم.
- بقي MutationObserver كما هو، وكذلك المصادقة ومفاتيح التخزين واللغة والاتجاه والثيم.
- بقيت روابط الأقسام القائمة؛ الرابط `/#assistant-preview` يفتح الآن تبويب المساعد مباشرة، ويمكن إعادة فتحه بعد اختيار تبويب آخر.
- لا تشخيص ولا تصنيف طبي جديد؛ المساعد ما زال معاينة معلنة غير متصلة بنموذج.

## الأدلة

- BEFORE: `artifacts/clinical-design/before/` — 24 حالة للرئيسية واللوحة قبل تغيير التطبيق.
- AFTER والتقرير الآلي: `artifacts/clinical-design/after/` و`report.json`.
- الأسماء تتبع `{ar|en}-{light|dark}-{390|768|1440}-{home|dashboard}.png`، مع نسخ `-viewport.png`.
- لقطات إضافية للحوار، CRUD، القائمة، الصفحات التي لم يُعد تصميمها، وأوضاع System والصلاحيات.

الاختبار يقيس تجاوز document والعناصر والحاويات، وتداخل أدوات التنقل، والتباين النصي المحسوب، وCairo وRTL/LTR، ولا يسمح بإخفاء تجاوز أفقي عالمي. يستخدم Edge حقيقيًا headless مع viewport محاكى، وليس أجهزة فعلية.

## حدود التحقق

التباين الآلي واللقطات ليسا شهادة امتثال WCAG أو اختبار قارئ شاشة شاملًا. فحص مفاتيح الترجمة غير المستخدمة استشاري، وبعض الاستدعاءات الديناميكية تظهر false positives؛ لم تُحذف ترجمات لإسكات الفاحص. تحذيرات Rollup الخاصة بتعليقات `@__PURE__` داخل Zod لم تُخفَ أو تُعالج بترقية غير لازمة.

لا يتضمن هذا العمل إعادة اختبار PostgreSQL أو خدمات المصادقة الحقيقية أو نشرًا. يلزم اعتماد المستخدم بصريًا قبل نقل الهوية إلى محتويات بقية الصفحات.
