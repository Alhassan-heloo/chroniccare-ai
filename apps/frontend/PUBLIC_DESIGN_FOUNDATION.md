# الأساس البصري والصفحات العامة — Premium Healthcare SaaS

## نطاق هذه الجولة

تحسين التنفيذ الموجود، لا إعادة بناء التطبيق. اقتصرت تعديلات الصفحات على الرئيسية وتسجيل الدخول
والتسجيل، مع تحسينات مشتركة في الرموز والأزرار والتفضيلات. حُفظت التعديلات السابقة الموجودة في
شجرة العمل، بما فيها صفحات المريض؛ لم تُعَد كتابتها أو التراجع عنها في هذه الجولة.

لم تتغير المصادقة أو مسارات الأدوار أو React Query أو الحسابات الصحية أو بيانات المثال.
لم يتغير Backend أو ملف بيئة أو اعتماد برمجي. لم يُجرَ اتصال بالخلفية أو قاعدة البيانات، ولم يُنفّذ commit أو push.

## مراجعة البنية والقرارات

- `components/ui`: المكونات الأساسية الحالية Button وInput وCard وBadge وModal مناسبة؛ لم تُستبدل بمكتبة جديدة.
- `components/layout`: Brand وPreferences وهيكل التطبيق الداخلي موجودة بالفعل؛ حُفظ اتجاه الهيكل الحالي.
- `components/public`: PublicHeader وCarePreview أساس قابل للاستخدام؛ أضيف PublicLayout لتوحيد الترويسة والتذييل.
- `pages/public/HomePage.tsx` و`pages/auth/AuthPage.tsx`: بقيت مسؤولة عن تركيب المحتوى وسلوكها الحالي.
- `i18n` و`theme`: بقيت آلياتهما كما هي. لم يُحذف MutationObserver، وحُميت الشجرة العامة المترجمة بالكامل بـ`data-i18n="declarative"`.
- `styles/globals.css`: بقي ملف الأنماط الحالي، دون إعادة تنظيم معماري أو تقسيم CSS.

كان الأساس يملك لوحة ألوان مشتركة بالفعل، لكن مقاسات النص والمسافات والاستدارة والارتفاع البصري
لم تكن ذات مقاييس مسماة. كما تكرر غلاف الصفحات العامة، وكان التذييل موجودًا في الرئيسية فقط.
عولج ذلك بمكونات صغيرة ورموز واضحة، لا بطبقات تصميم معقدة.

## نظام التصميم

- الألوان: خلفية فاتحة هادئة، أسطح واضحة، أزرق طبي ونص كحلي، ولمسات teal. الألوان الدلالية الحالية للنجاح والتحذير والخطأ محفوظة.
- الداكن: نفس الأدوار الدلالية مع أسطح slate ونصوص وأزرار عالية الوضوح، دون تغيير إدارة الثيم.
- الخط: Cairo المحلي كما هو، مع مقاييس `--text-xs` حتى `--text-display`.
- المسافات: إيقاع 4px عبر `--space-1` حتى `--space-16`؛ لا تعديل شامل لمقاسات الصفحات الداخلية.
- الاستدارة: `--radius-sm/md/lg/xl` والتحكمات؛ ظلال `--shadow-card` و`--shadow-raised`.
- الأزرار: الإبقاء على primary/secondary/ghost، وإضافة `loading` اختياري متوافق رجعيًا، مع تعطيل الزر و`aria-busy` ومؤشر يحترم reduced-motion.
- النماذج: الحقول وتسميات الإدخال والتحقق والإكمال التلقائي وإظهار كلمة المرور محفوظة، مع أسطح وحدود ومقاسات أوضح.
- البطاقات والشارات: تبقى Card وBadge مصدر الأنماط المشتركة؛ بطاقات ميزات الرئيسية تستخدم نفس أساس Card.
- `SectionHeading`: عنوان قسم دلالي مع وصف وeyebrow وإجراء اختياري.
- `Feedback`: حالات error/success/info/loading/empty، مع أيقونات زخرفية ومناطق تنبيه مناسبة. يمرر المستدعي النص المترجم؛ لا طبقة ترجمة إضافية.

## الصفحات العامة

- الرئيسية: افتتاحية جانبية على الشاشات الواسعة، معاينة توضيحية واضحة، ثلاث بطاقات للميزات، ودعوة إجراء موحدة. لا ادعاءات بوجود AI طبي أو بيانات حقيقية.
- الترويسة: روابط «عن المنصة / معاينة الواجهة»، مع الحفاظ على روابط الحساب والعرض التجريبي والتفضيلات.
- الدخول والتسجيل: مساحة نموذج محددة بإطار وظل هادئ، قصة جانبية على الكمبيوتر، وتخطيط عمودي على الجوال، ورسائل مشتركة للنجاح والخطأ وانتهاء الجلسة.
- التذييل: مشترك بين الصفحات الثلاث، ويحتفظ بتوضيح الطبيعة الأكاديمية والبيانات التجريبية.
- الأرقام الزخرفية تستخدم formatter المركزي؛ لا تغيير للقراءات أو الوحدات الصحية.

ثبت في المتصفح أن روابط React Router ذات fragment تحتاج تمريرًا صريحًا إلى القسم.
أضيف effect محدود في PublicLayout للمعرّفين العامين فقط، بما يشمل النقر المتكرر والعودة عبر التنقل.
لا يغير المسار أو query أو hash، ولا يُعاد تشغيله عند تغيير اللغة وحدها.

لوحظ أيضًا أن زر الثيم يتبع الدورة الحالية Light → Dark → System → Light، بينما كانت تسميته
تَعِد بالتبديل المباشر إلى الفاتح/الداكن. صُححت الأيقونة والتسمية لوصف الوضع التالي بدقة، دون تغيير الدورة أو ThemeProvider.

## التحقق

النتائج الفعلية بعد آخر تعديلات المصدر:

| الفحص | النتيجة |
| --- | --- |
| TypeScript للتطبيق والسكربتات | PASS |
| ESLint | PASS |
| `check:translations` | PASS — 290 مفتاحًا متطابقًا وplaceholders متوافقة |
| `test:smoke` | PASS — 14 مسارًا، الترجمة، التحقق، CRUD، ملخصات وتقارير البيانات التجريبية |
| Production build | PASS |
| `git diff --check` | PASS |
| Edge/Playwright `design-browser.mjs --public-only` | PASS — 46 حالة قياس وتصوير ومجموعتا تفاعل |

التغطية البصرية للصفحات الثلاث **بكلتا اللغتين**:

| العرض | إعداد الثيم |
| --- | --- |
| 320px | Light |
| 390px | Dark، مع اختبار تفاعلي للأوضاع الثلاثة وSystem/OS Light وDark |
| 430px | Dark |
| 768px | System مع OS Light |
| 1024px | Light |
| 1440px | Light |

36 حالة عرض أساسية، و10 صور إضافية لحالات التحقق والتحميل والنجاح والخطأ وSystem/Dark.
نجح حفظ اللغة والثيم وإعادة التحميل، وتبديل اللغة أربع مرات مع حفظ حقول النموذج والمسار وquery وhash،
وتحويل روابط الأقسام إلى مواضعها الفعلية، وإظهار كلمة المرور، والتركيز على الحقل غير الصحيح.
نجح الانتقال إلى Demo ثم القياسات مع بقاء 14 قراءة تمثل الأيام السبعة. لا تغيير دائم للبيانات.
هذه تغطية موجهة وليست جميع التوافيق الممكنة للأحجام والثيمات.

سُجلت صفر أخطاء runtime وصفر تحذيرات Console غير متوقعة. لم يُرصد overflow للوثيقة أو الحاويات
المحددة، أو تداخل في مجموعات التحكم المفحوصة، أو تجاوز عناصر لحدود العرض. لم يُستخدم إخفاء أفقي
عام. اجتازت عينات تباين نص الصفحة والزر الأساسي حد 4.5:1؛ ليست تدقيق تباين شاملًا لكل عنصر.
رُوجعت لقطات فعلية للرئيسية والدخول والتسجيل، على الكمبيوتر والجوال واللوحي، لا نتائج build فقط.

الأوامر المناسبة داخل `apps/frontend`:

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run check:translations
npm.cmd run test:smoke
npm.cmd run build
git diff --check
```

لتشغيل الاختبار البصري باستخدام Playwright الموجود أصلًا في البيئة:

```powershell
# عند عدم وجود playwright ضمن مسارات Node، حدّد مسار الحزمة المتاحة محليًا:
$env:PLAYWRIGHT_MODULE_PATH = 'C:\path\to\existing\node_modules\playwright'
npm.cmd run test:design-browser -- --public-only
```

هذا الخيار يستخدم Edge وخادم Vite مؤقتًا على 5178، ويوقف عمليته الخاصة في النهاية.
طلبات المصادقة معترضة ببيانات اختبار داخل المتصفح؛ ليست تحققًا من Backend.
التقارير والصور في `artifacts/public-foundation/after/`، وهي نواتج محلية لا ملفات مصدر.

## الحدود والخطوة التالية

- التحقق البصري ليس تدقيق WCAG شاملًا أو اختبار Safari/Firefox أو أجهزة محمولة فعلية.
- لم تُختبر مصادقة حقيقية أو قاعدة البيانات عمدًا التزامًا بالنطاق.
- تبقى تحذيرات Zod الخاصة بتعليقات PURE وملاحظات الترجمة الديناميكية منفصلة عن نجاح البناء والترجمة؛ لم تُخفَ.
- النسخة الافتراضية من Node في جلسة الأدوات لم تنتج نتائج قابلة للاعتماد. استُخدمت نسخة Node عاملة متاحة بالفعل، مع PATH مؤقت لعملية الفحص فقط، دون تثبيت أو تعديل دائم للجهاز.

الطلب المقترح التالي: «طبّق الأساس البصري الحالي على لوحة المريض فقط، مع إعادة استخدام المكونات
المشتركة والحفاظ على الحسابات والرسوم والعمليات وبيانات الأسبوع التجريبية وi18n والثيمات.
ابدأ بمراجعة التنفيذ الموجود، ولا تتصل بالخلفية أو تُعد تصميم بقية صفحات المريض في هذه الجولة.»
