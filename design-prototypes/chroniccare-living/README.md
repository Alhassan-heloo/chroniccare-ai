# ChronicCare Living 2.0 — A Living Health Experience

نموذج تصميم تفاعلي مستقل، باتجاه **Next-Generation Clinical Experience**. لا يُعدّل التطبيق الأصلي، ولا يتصل بـBackend أو قاعدة بيانات أو نظام حسابات أو AI أو خدمات إشعارات.

## جولة الصقل الحالية — 0.2.1

حُفظت نسخة Living 2.0 قبل هذه الجولة في `../chroniccare-living-2.0-reference-20261023`، دون node_modules أو junctions أو cache أو dist. صور المرجع الفعلية موجودة داخلها في `before-screenshots/`. المرجع الأقدم المذكور أدناه بقي كما هو.

أُضيف توقيع خطّي زخرفي ثابت، وتدرج مقروء للعنوان، وعلامات أقسام متسقة، وحالات hover/focus بألوان الوظائف، وحلقات للعادات بدل تكرار الأشرطة، وتراجع مستقل عن آخر تحديث للماء والمشي. التقرير في الرئيسية مختصر وقابل للتوسيع، بينما يفتح كاملًا في الحوار. جميع الأرقام والمتوسطات وأهداف المثال محفوظة.

التنقل يتبع التمرير دون تغيير الرابط أو نقل التركيز تلقائيًا، مع إزاحة محسوبة للرأس العائم. المساعدة تعمل باللمس ولوحة المفاتيح وEscape، ويظهر تاريخ أحدث قراءة مستقلًا عن تاريخ اليوم المحدد. مقياس أعمدة الأسبوع يبدأ الآن من صفر؛ هذا تعديل تمثيل بصري، وليس تغييرًا للبيانات أو الحسابات الصحية.

فُحصت الخلفية قبل التعديل وبعده: لم تتغير عينات ألوان الهامش أثناء التمرير ولم تُرصد قفزات حادة، ولذلك لم تُعدّل طبقة الخلفية الصحيحة لتعويض أثر التصوير المجمع.

نتائج الجولة وقائمة الملفات والتغطية والحدود في [VALIDATION.md](VALIDATION.md).

## تطور 2.0 والنسخة المرجعية

حُفظ التصميم المعتمد قبل التعديل في المجلد المجاور `chroniccare-living-approved-reference-20261023`، مع مصادره وأصوله وإعداداته ولقطات Edge الفعلية في `before-screenshots/`. النسخة المرجعية لا تحتوي node_modules أو cache أو dist؛ لم تُستبدل أو تُحذف ملفاتها.

- هوية Ocean Graphite: خلفية `#0B1320`، سطح مرتفع `#162437`، أكوا `#69E1D7`، وأزرق `#80A8FF`، مع نسخة فاتحة متوازنة.
- ألوان وظيفية لا تصنيفات طبية: مرجاني للضغط، أزرق للسكر، بنفسجي للأدوية، نعناعي للعادات، كهرماني للتقارير، وأكوا للمساعد. الأسماء والأيقونات تظل موجودة بجانب اللون.
- لوحة Bento غير متساوية: الرسم والقراءات أولًا، الروتين بجانبه على سطح المكتب، ثم التقارير والمساعد. يعاد ترتيبها في الجهاز اللوحي والجوال دون إخفاء أي ميزة.
- فهرس أقسام تفاعلي في الرئيسية، وفصل أوضح للقراءة المحددة وأحدث قراءة. يظهر زر دخول المساحة مع المعاينة في أول شاشة 1440×960 باللغتين.
- شريط جرعات مسجلة، وتغذية راجعة للجرعات والتراجع والعادات والرسم وتبديل المظهر؛ لا إضاءة متحركة باستمرار.
- الأيقونات من Lucide الموجود مسبقًا؛ لم تُضف اعتماديات جديدة. جميع البيانات والحسابات والتخزين المؤقت وتفاعلات النسخة الأصلية محفوظة.

مقارنتا «قبل/بعد» الفعليتان: `artifacts/comparison-home.png` و`artifacts/comparison-dashboard.png`. لإعادة توليدهما بعد اختبار المتصفح، نفّذ `npm.cmd run compare` مع إعداد `PLAYWRIGHT_MODULE_PATH` المذكور أدناه. تعرض المقارنة الحالية Living 2.0 المعتمدة يسارًا والنسخة المصقولة يمينًا بنفس الأبعاد.

### الاعتماديات في بيئة التنفيذ الحالية

أُعيد استخدام حزم المشروع المثبتة مسبقًا عبر **junction محلي متجاهل باسم `node_modules`** إلى `apps/frontend/node_modules`. لم تُثبت أو تُرقَّ حزم التطبيق. cache الخاص بـVite معزول في `.vite-cache` داخل النموذج.

**لا حاجة إلى `npm install` في هذه النسخة المحلية، ولا تنفّذه بينما `node_modules` رابط إلى التطبيق.** لتجربة تثبيت مستقل لاحقًا، انسخ مجلد النموذج دون `node_modules` أو ملفات runtime/cache، ثم نفّذ `npm.cmd install --workspaces=false` داخل النسخة المستقلة. جميع اعتماديات النموذج معلنة في `package.json`؛ التثبيت الشبكي النظيف لم يُختبر هنا.

React وReact DOM هما أساس الواجهة، وLucide للأيقونات (موجود أصلًا في المشروع). TypeScript وVite وESLint أدوات التطوير والتحقق. لا مكتبة رسوم أو حركة إضافية. Cairo وخط ترخيصه ومصدره من الأصول المحلية الموجودة في المشروع.

## التكوين والتفاعلات

- تنقل زجاجي عائم مع قائمة جوال، لغة عربية/إنجليزية، RTL/LTR، ومظهر فاتح/داكن. التفضيلات محفوظة بمفاتيح `cc-living-*`، مستقلة عن التطبيق.
- مقدمة تتضمن رسمًا تفاعليًا فعليًا، ثم مشاهد للأسبوع والروتين والتقرير والمساعد؛ ليست صورة واجهة أو شبكة مزايا مكررة.
- لوحة المريض تتمحور حول **Adaptive Health Canvas**، مع تنقل مضغوط وروتين جانبي متكيف، بدل صف بطاقات KPI متساوية.
- تبديل الضغط/السكر، تفاصيل التحويم، اختيار النقاط بلوحة المفاتيح، ومنزلق لاختيار اليوم على الجوال. جدول نصي بديل يعرض القيم والوحدات.
- حوار إضافة قراءة مع تحقق وتركيز داخل الحوار. في هذا النموذج تُحدَّث سلسلة القياس المختارة في **اليوم الأخير من نافذة المثال**، وتبقى سبعة أيام. تظهر النتيجة في الرسم والتقرير، ويعود تحديد الرسم لأحدث يوم عند تغيير قيمه.
- تسجيل/التراجع عن جرعات توضيحية، إضافة كوب، إضافة 500 خطوة حتى هدف المثال، وتبديل فترة التقرير بين 3 و7 أيام.
- معاينة إشعارات مع تحديدها كمقروءة، دون إرسال إشعارات فعلية.
- مساعد قابل للتوسيع واختيار سؤال توضيحي، **دون توليد إجابة أو ادعاء اتصال بنموذج**.
- أزرار الدخول والتسجيل تفتح حوارًا يوضح استقلال النموذج ويتيح دخول العرض. لا تطلب بيانات شخصية أو كلمة مرور، ولا تنشئ حسابًا حقيقيًا أو محاكاة أمنية مضللة.
- تبديل الشاشة يحفظ حالة التجربة في الذاكرة. إعادة التحميل تعيد أمثلة الصحة الأصلية؛ لا تُحفظ البيانات الصحية في localStorage.

## التصميم والحركة

التوكنز مركزية في `src/style.css`: الأزرق الطبي والأكوا، درجتا ظهور فاتحة/داكنة، أسطح زجاجية، حدود شعرية، radius وblur وshadows ومسافات ومدة/easing للحركة.

الحركة: دخول متدرج، ظهور الضوء المحيطي مرة واحدة، كشف المسارات، انتقالات الضوابط والتوسيع، ومشاهد reveal-on-scroll. إعداد `prefers-reduced-motion` يعطّل الحركة والتمرير الناعم. توجد بدائل للأسطح عند عدم دعم backdrop-filter وعند طلب تقليل الشفافية.

القيم الصحية توضيحية فقط؛ لا تصنيفات سريرية أو درجات صحة أو تشخيص أو نصائح علاجية أو أجهزة ذكية أو بيانات مرضى. الأهداف والأسماء والمواعيد أمثلة صريحة. لم تصل صورة مرجعية ضمن المرفق النصي؛ اتُّبع الوصف المكتوب دون ادعاء مطابقة صورة.

## أوامر التحقق

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
```

اختبار المتصفح يستخدم Playwright الموجود في البيئة، دون إضافته إلى حزم التشغيل:

```powershell
$env:PLAYWRIGHT_MODULE_PATH='C:\Users\msi\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules\playwright'
npm.cmd run test:browser
```

يلزم Edge مثبتًا. يشغّل الاختبار خادمًا مؤقتًا على **5206** ويغلق فقط الخادم الذي أنشأه. يرفض المنفذ المشغول ولا يوقف خوادم أخرى. النتائج واللقطات في `artifacts/`، والتفاصيل في `VALIDATION.md`.

بعد تشغيل `npm.cmd run dev` في نافذة مستقلة، يمكن تشغيل الفحص المركز واللقطات على المنفذ 5205:

```powershell
npm.cmd run test:polish
npm.cmd run review
npm.cmd run compare
```

تستخدم هذه الأوامر إعداد `PLAYWRIGHT_MODULE_PATH` نفسه. الفحص المركز يتحقق من المساعدة والتراجع والتتبّع والتقرير في 3 سيناريوهات؛ `review` يلتقط الواجهتين ويختبر الخلفية؛ `compare` يقرأ اللقطات المحفوظة ولا يحتاج خادمًا. النتائج في `artifacts/polish/` و`artifacts/review/`.

الاختبار لا يعدّل بيانات التطبيق الأصلي. لا تنقل التصميم إلى التطبيق إلا بعد موافقة صريحة.
